# Contributing

Obrigado por considerar contribuir para este repositório! Abaixo estão algumas diretrizes rápidas para facilitar contribuições de alta qualidade.

## Como contribuir

1. Abra uma issue para discutir a sua ideia antes de implementar mudanças significativas.
2. Fork o repositório e crie uma branch com nome descritivo: `feat/nome-da-funcionalidade` ou `fix/descrição-curta`.
3. Faça commits pequenos e atômicos com mensagens claras (ex.: `feat: adicionar script de deploy`).
4. Envie um Pull Request apontando para a branch `main` e descreva o que foi feito.

## Padrão de commits

Sugerimos mensagens no estilo semantic (ex.: `feat:`, `fix:`, `chore:`, `docs:`). Isso ajuda a manter um histórico claro.

## Testes e qualidade

- Se o projeto tiver testes, execute-os localmente antes de enviar o PR.
- Inclua testes para bugs corrigidos e novas funcionalidades sempre que possível.

## Revisão de PR

- PRs pequenos e focados são mais fáceis de revisar.
- Mantenha a descrição do PR clara, inclua prints ou steps para reproduzir quando aplicável.

## Estilo de código

- Siga padrões comuns da linguagem (PEP8 para Python, por exemplo).
- Execute linters/formatadores quando aplicável.

## Licença

Ao contribuir, você concorda que sua contribuição será licenciada sob a mesma licença do repositório.
